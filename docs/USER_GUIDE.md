## 1. تسجيل الدخول 🔐

### الوصول لصفحة الدخول

1. افتح المتصفح وانتقل إلى رابط النظام
2. ستظهر صفحة تسجيل الدخول

![Login Page](./screenshots/login.png)

### بيانات الدخول

| الحقل | الوصف |
|-------|-------|
| **البريد الإلكتروني** | البريد المسجل في النظام |
| **كلمة المرور** | كلمة المرور الخاصة بك |

### خطوات تسجيل الدخول

```
1. أدخل البريد الإلكتروني
2. أدخل كلمة المرور
3. اضغط على زر "تسجيل الدخول" أو اضغط Enter
```

### 🔒 الأمان

- ✅ يتم تسجيل الخروج تلقائياً بعد فترة من عدم النشاط
- ✅ تغيير كلمة المرور بشكل دوري
- ✅ عدم مشاركة بيانات الدخول مع الآخرين

### استعادة كلمة المرور

في حالة نسيان كلمة المرور:

1. اضغط على "نسيت كلمة المرور؟"
2. أدخل البريد الإلكتروني
3. سيتم إرسال رابط إعادة التعيين

## 2. إجراء عملية بيع 💰

### الوصول لنقطة البيع

من القائمة الجانبية، اضغط على **"نقطة البيع"** أو اضغط `F2`

![POS Page](./screenshots/pos.png)

### خطوات إجراء عملية بيع

#### 📦 الخطوة 1: إضافة المنتجات للسلة

**الطريقة الأولى: البحث بالاسم**
```
1. اكتب اسم المنتج في خانة البحث
2. اضغط على المنتج من النتائج
3. سيُضاف تلقائياً للسلة
```

**الطريقة الثانية: مسح الباركود**
```
1. وجه الماسح الضوئي نحو الباركود
2. سيُضاف المنتج تلقائياً للسلة
```

**الطريقة الثالثة: التصفح بالتصنيفات**
```
1. اختر التصنيف من الأعلى
2. اضغط على المنتج المطلوب
3. سيُضاف للسلة
```

#### 🔢 الخطوة 2: تعديل الكميات

```
• اضغط على +/- لزيادة أو تقليل الكمية
• أو أدخل الكمية مباشرة في الحقل
• اضغط على أيقونة الحذف لإزالة المنتج
```

#### 👤 الخطوة 3: ربط العميل (اختياري)

```
1. اضغط على "اختيار عميل"
2. ابحث عن العميل بالاسم أو الهاتف
3. اختر العميل من القائمة
4. سيتم ربط الفاتورة بالعميل
```

#### 💳 الخطوة 4: الدفع

```
1. اضغط على زر "الدفع" أو اضغط F12
2. اختر طريقة الدفع:
   - نقدي 💵
   - بطاقة 💳
   - تحويل 🏦
3. أدخل المبلغ المدفوع
4. اضغط "تأكيد"
```

#### 🖨️ الخطوة 5: طباعة الإيصال

```
• سيتم طباعة الإيصال تلقائياً
• اضغط "إعادة الطباعة" إذا لزم الأمر
```

### ⌨️ اختصارات نقطة البيع

| الاختصار | الإجراء |
|----------|---------|
| `F2` | فتح نقطة البيع |
| `F3` | البحث عن منتج |
| `F4` | اختيار عميل |
| `F8` | الدفع |
| `F12` | تأكيد الفاتورة |
| `Delete` | حذف العنصر المحدد |
| `Escape` | إلغاء العملية |

### 💡 نصائح مهمة

> 💡 **نصيحة:** استخدم الماسح الضوئي لتسريع عملية البيع

> ⚠️ **تنبيه:** تأكد من فتح وردية قبل البدء بالبيع

> 📌 **ملاحظة:** يمكنك تعليق الفاتورة والعودة لها لاحقاً

## 3. إدارة المنتجات 📦

### الوصول لصفحة المنتجات

من القائمة الجانبية: **المنتجات** ← **جميع المنتجات**

أو اضغط `F3`

![Products Page](./screenshots/products.png)

### إضافة منتج جديد

#### 📝 البيانات الأساسية

```
1. اضغط على زر "إضافة منتج"
2. املأ البيانات المطلوبة:
   ┌─────────────────────────────────┐
   │ الباركود (إلزامي)               │
   │ الاسم (إلزامي)                  │
   │ الاسم بالعربية                  │
   │ الوصف                           │
   │ التصنيف                         │
   │ العلامة التجارية                │
   │ المورد                          │
   └─────────────────────────────────┘
```

#### 💰 الأسعار

```
   ┌─────────────────────────────────┐
   │ سعر التكلفة                     │
   │ سعر البيع (إلزامي)              │
   │ سعر الجملة                      │
   └─────────────────────────────────┘
```

#### 📊 المخزون

```
   ┌─────────────────────────────────┐
   │ الكمية الحالية                  │
   │ الحد الأدنى للتنبيه             │
   │ الحد الأقصى                     │
   │ الوحدة (قطعة، كجم، إلخ)         │
   └─────────────────────────────────┘
```

#### ✅ الحفظ

```
3. اضغط "حفظ" لإضافة المنتج
```

### تعديل منتج

```
1. ابحث عن المنتج المطلوب
2. اضغط على أيقونة التعديل ✏️
3. عدّل البيانات المطلوبة
4. اضغط "حفظ"
```

### حذف منتج

```
1. اضغط على أيقونة الحذف 🗑️
2. أكد عملية الحذف
```

> ⚠️ **تنبيه:** لا يمكن حذف منتج مرتبط بفواتير

### طباعة الباركود

```
1. اختر المنتجات المطلوبة
2. اضغط "طباعة باركود"
3. اختر إعدادات الطباعة:
   - حجم الملصق
   - عدد النسخ
   - البيانات المعروضة
4. اضغط "طباعة"
```

### استيراد المنتجات من Excel

```
1. اضغط "استيراد" في أعلى الصفحة
2. حمّل ملف Excel
3. راجع البيانات المستوردة
4. اضغط "تأكيد الاستيراد"
```

**تنسيق ملف Excel:**

| الباركود | الاسم | التصنيف | سعر التكلفة | سعر البيع | الكمية |
|----------|-------|---------|-------------|-----------|--------|
| 12345678 | منتج 1 | تصنيف أ | 10 | 15 | 100 |

## 4. إدارة العملاء 👥

### الوصول لصفحة العملاء

من القائمة الجانبية: **العملاء**

![Customers Page](./screenshots/customers.png)

### إضافة عميل جديد

```
1. اضغط "إضافة عميل"
2. املأ البيانات:
   ┌─────────────────────────────────┐
   │ الاسم (إلزامي)                  │
   │ رقم الهاتف                      │
   │ البريد الإلكتروني               │
   │ العنوان                         │
   │ الرقم الضريبي                   │
   │ ملاحظات                         │
   └─────────────────────────────────┘
3. اضغط "حفظ"
```

### عرض سجل العميل

```
1. اضغط على اسم العميل
2. ستظهر صفحة تفاصيل العميل:
   - المعلومات الأساسية
   - سجل المشتريات
   - إجمالي المشتريات
   - الفواتير السابقة
```

### نظام الولاء والنقاط

```
• تُحسب نقطة لكل [مبلغ] مشتريات
• يمكن استبدال النقاط بخصومات
• عرض رصيد النقاط في صفحة العميل
```

## 5. التقارير 📊

### الوصول للتقارير

من القائمة الجانبية: **التقارير**

![Reports Page](./screenshots/reports.png)

### أنواع التقارير

#### 📈 تقرير المبيعات

```
• المبيعات اليومية
• المبيعات الأسبوعية
• المبيعات الشهرية
• مقارنة الفترات
```

**فلترة التقرير:**
```
1. اختر الفترة الزمنية
2. اختر الفرع (اختياري)
3. اضغط "عرض التقرير"
```

#### 📦 تقرير المنتجات

```
• المنتجات الأكثر مبيعاً
• المنتجات الأقل مبيعاً
• حركة المخزون
• تنبيهات المخزون المنخفض
```

#### 💰 تقرير الأرباح

```
• إجمالي المبيعات
• إجمالي التكلفة
• هامش الربح
• الربح الصافي
```

#### 👥 تقرير العملاء

```
• العملاء الأكثر شراءً
• العملاء الجدد
• معدل الشراء
```

### تصدير التقارير

```
1. اعرض التقرير المطلوب
2. اضغط على "تصدير"
3. اختر التنسيق:
   - PDF 📄
   - Excel 📊
   - CSV 📝
4. سيتم تحميل الملف
```

## 6. إدارة الورديات ⏰

### فتح وردية جديدة

```
1. من القائمة: الورديات ← إدارة الورديات
2. اضغط "فتح وردية جديدة"
3. أدخل:
   ┌─────────────────────────────────┐
   │ النقدية الافتتاحية              │
   │ ملاحظات (اختياري)               │
   └─────────────────────────────────┘
4. اضغط "تأكيد"
```

### أثناء الوردية

```
• جميع المبيعات تُسجل تحت الوردية الحالية
• يمكنك إضافة مصروفات للوردية
• عرض ملخص الوردية في أي وقت
```

### إغلاق الوردية

```
1. اضغط "إغلاق الوردية"
2. أدخل:
   ┌─────────────────────────────────┐
   │ النقدية الفعلية                 │
   │ ملاحظات الإغلاق                 │
   └─────────────────────────────────┘
3. سيُعرض تقرير Z:
   - إجمالي المبيعات
   - المبيعات حسب طريقة الدفع
   - المصروفات
   - الفرق في النقدية
4. اضغط "تأكيد الإغلاق"
```

## 🔧 استكشاف الأخطاء وإصلاحها

### مشاكل شائعة

#### لا يعمل الماسح الضوئي
```
1. تأكد من توصيل الماسح
2. جرب في برنامج آخر (Notepad)
3. أعد تشغيل المتصفح
```

#### لا تُطبع الإيصالات
```
1. تأكد من توصيل الطابعة
2. تحقق من إعدادات الطباعة
3. جرب طباعة صفحة اختبار
```

#### بطء في التحميل
```
1. تحقق من الاتصال بالإنترنت
2. امسح ذاكرة التخزين المؤقت
3. أعد تحميل الصفحة
```
